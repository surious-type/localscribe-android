# LocalScribe architecture

The binding product requirements are in [product-spec.md](product-spec.md).

## Decisions

Use a pure Kotlin `:core` module for contracts and deterministic algorithms and an Android `:app` module for adapters, Compose UI, Room, services and JNI. Package root: `io.github.surioustype.localscribe`. Android minimum API 26; compile/target current stable SDK verified during bootstrap. No audio uploads, telemetry, analytics or automatic crash reporting. Network adapters only download public models/catalogs and app updates.

Prefer a small explicit application dependency container over a dependency-injection framework. Room owns jobs, chunks, raw segments, installed models and benchmark records. ViewModels observe Flows; neither service nor UI is a durable source of truth.

## Boundaries and ownership

`core/model` contains immutable entities; `core/ports` contains interfaces. Bootstrap owns these until frozen. Feature agents may request contract amendments from the lead but must not change shared contracts concurrently.

* `AudioRepository`: list MediaStore, import SAF/share URI, persist metadata and permission state.
* `AudioPipeline`: decode a requested time window to mono 16 kHz float PCM with bounded memory. No whole-recording PCM cache; safe gain only, no default denoise.
* `TranscriptionEngine`: load verified model, transcribe PCM with bounded prompt and cancellation, close native resources. One session owns one native context.
* `TranscriptionRepository`: atomic claim, chunk completion with raw segments, recovery and guarded job transitions.
* `TranscriptAssembler`: derive merged transcript without changing stored raw results.
* `ModelCatalogRepository`, `ModelDownloadManager`, `InstalledModelRepository`: public catalog, verified resumable downloads and model lifecycle. Independent of app updates.
* `BenchmarkManager`, `RecommendationEngine`, `DemoAudioRepository`: real timings and licensed sample references; recommendations never initiate downloads.
* `AppUpdateManager`: flavor-specific public GitHub releases adapter, version/hash/package/signing checks and system installer handoff. Play implementation disables self-update.
* `ExportManager`: deterministic TXT/Markdown/SRT/VTT/JSON output; Android adapter writes via SAF/share.

## Execution and recovery

Default windows are 90 seconds with 3 seconds overlap (configurable). Persist the complete chunk plan before processing. Claim and increment attempts transactionally; commit raw segments and COMPLETED atomically. Cancellation never commits a partially transcribed chunk. Recover PROCESSING chunks to PENDING and interrupted RUNNING jobs to PAUSED on cold start. Resume skips COMPLETED chunks. Never automatically launch a restricted foreground service at boot.

One foreground service serializes jobs and holds the model between chunks. Pause/stop persist intent and abort native work when needed. Timeout, thermal critical state and lost source access are actionable persistent states, not retry loops. Android service-type compatibility and time limits must be handled explicitly.

## Presentation

Material 3, edge-to-edge, adaptive width, light/dark and optional dynamic colors. Onboarding → recordings/import → progress → transcript with seek/search/export. Separate Models/benchmark/demo and Settings/Updates. Keep stack traces and sensitive filenames/transcript contents out of logs and error UI.

## Verification

Domain unit tests cover chunk boundaries, deduplication, WER/CER, benchmark math, recommendations, versions, release parsing, state transitions and export escaping. Room instrumentation covers transactional checkpoint and schema/migrations; Compose smoke tests exercise onboarding/import/navigation. Native smoke test is opt-in with a separately supplied small verified model. No production key is generated by agents.
